    Sparrow

    All methods in the Electrum query interface are also served here, with server.features advertising silent payment support. An http/s + ws/s transport is supported on the same port.
    Transport tcp/s, http/s, ws/s
    Framing json-rpc 2.0
    Auth tls server, mutual
    Channel full duplex (subscriptions)

    Block statistics

    Method Parameters Status Notes
    blockchain.block.stats height number WIP bitcoind getblockstats subset

    Silent payment (bip352) scanning, one subscription per address

    Method Parameters Status Notes
    blockchain.silentpayments.subscribe scan_private_key string, spend_public_key string, start? = empty::value, labels? = empty::array WIP bip352, one subscription per scan key pair
    blockchain.silentpayments.unsubscribe scan_private_key string, spend_public_key string WIP returns the dropped scan address
