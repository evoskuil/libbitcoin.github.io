    bitcoind JSON-RPC

    Drop-in compatibility for JSON-RPC node methods. A tcp/s transport is supported on the same port.
    Transport tcp/s, http/s, ws/s
    Framing json-rpc 2.0
    Auth tls server, mutual; http basic (scoped)
    Channel half duplex
