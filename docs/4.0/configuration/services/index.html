    Services

    Client-facing services. Each has its own binds, TLS and credentials and is disabled when it has no bind.

    [wallet]

    Setting Type Default Description
    p2kh_prefix byte 0 (use '111' for testnet) The pay-to-public-key-hash address prefix.
    p2sh_prefix byte 5 (use '196' for testnet) The pay-to-script-hash address prefix.
    wif_prefix byte 128 (use '239' for testnet) The wallet import format prefix.
    witness_prefix text bc (use 'tb' for testnet) The witness address prefix.
    hd_private_prefix integer 76066276 (use '70615956' for testnet) The extended private key prefix.
    hd_public_prefix integer 76067358 (use '71979618' for testnet) The extended public key prefix.

    [admin]

    Setting Type Default Description
    bind address list empty (disabled) IP address to bind, multiple allowed.
    safe address list empty (disabled) IP address to secure bind, multiple allowed.
    cert_auth path The certificate authority directory (*.PEM), enables client authentication.
    cert_path path unused The path to the server certificate file (.PEM).
    key_path path unused The path to the server private key file (.PEM).
    key_pass text The password to decrypt the server private key file (.PEM), optional.
    connections integer 0 The required maximum number of connections.
    rate_limit integer 0 (network controls) The send rate limit in bytes per second.
    connect_timeout_seconds integer 0 (network controls) The time limit for connection establishment.
    inactivity_minutes integer 10 The idle timeout (http keep-alive).
    expiration_minutes integer 60 The idle timeout (http keep-alive).
    minimum_buffer integer 4000000 The minimum retained read buffer size.
    maximum_backlog integer 10485760 The maximum write backlog of a channel.
    maximum_buffer integer 65536 The maximum json response buffer size.
    maximum_request integer 4000000 The maximum allowed request size.
    server text `` The server name (http header).
    host endpoint list empty (disabled) The host name (http verification), multiple allowed.
    origin endpoint list empty (disabled) The allowed origin (see CORS), multiple allowed.
    allow_opaque_origin boolean false Allow requests from opaque origin (see CORS), multiple allowed.
    path path empty The required root path of source files to be served.
    default text index.html The path of the default source page.
